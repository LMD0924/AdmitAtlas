# REST 接口约定

> 状态口径：**P1 单省试点 + 双身份体系（2026-11）**。除标注「计划」的采集/发布接口外，下表端点均已实现；默认数据集为演示数据 `demo-2026-hb-v1`（合成值，非真实录取分数）。系统区分**游客 / 学生 STUDENT / 管理员 ADMIN** 三种访问身份。

## 通用约定

- Base URL：`/api/v1`。后端为模块化单体，只有 `8080` 一个端口（launcher 应用）；前端 Vite 代理 `/api` → `http://localhost:8080`。
- `GET /api/v1/system/modules` 为单应用自检端点，返回当前启动类扫描到的全部业务模块与运行端口。
- 所有响应统一包装：

```json
{ "code": 0, "message": "success", "data": {}, "timestamp": 1730000000000 }
```

- `code = 0` 表示成功；非 0 时 `data` 为 `null`，前端 Axios 拦截器解包 `body.data` 并把业务码保留在 `apiError.code` 中。业务错误**统一走 HTTP 200 + code**，不走 HTTP 状态码；仅真正的 404 保持 HTTP 404。
- 分页参数：`page`（从 1 开始）、`size`（默认 20，最大 200）。
- **认证**：登录后在请求头带 `Authorization: Bearer <JWT>`。JWT 为 HS256，默认 12 小时有效期（`admitatlas.auth.token-hours`），密钥由 `ADMITATLAS_AUTH_SECRET` 注入。
- **令牌失效**：除验签与 `exp` 外，每次请求还回查账号 `status` / `role` / `token_version`。退出登录、停用账号、重置密码都会使已签发 token 立即失效。
- **禁止**在任何响应中出现「录取率 / 保证录取」等承诺性字段，统一使用 `matchScore`（0~100 匹配度）与 `tier`（CHONG / WEN / BAO）；每个结果都带统一 `disclaimer`。
- 跨年只比较 `minRank`，`minScore` 仅用于展示；一次匹配的所有读取固定在同一 `dataVersion`。
- 学生只能读写自己的成绩 / 匹配任务 / 方案；管理员可在后台跨账号核查。用户列表与任何响应都**不返回 `password_hash`**。

## 三级权限

| 级别 | 路径 | 规则 |
|---|---|---|
| `PUBLIC` | 未登记的其他路径（含未知路径） | 游客可用；带有效 token 时写入身份上下文供个性化展示；无效 token 按游客处理。**不存在的路径仍是真正的 404**，不会被鉴权层改成 401 |
| `AUTHENTICATED` | `/api/v1/student/**`、`/api/v1/plans/**`、`/api/v1/match/analyze`、`/api/v1/match/tasks/**`、`/api/v1/auth/logout`、`/api/v1/users/profile`、`/api/v1/users/password`、`/api/v1/users/avatar` | 学生与管理员可用；无有效 token 返回 `code = 401` |
| `ADMIN` | `/api/v1/admin/**` | 仅 ADMIN；未登录 `401`，学生 `403` |

> ⚠️ 受保护路径是**显式登记**的（`common-core/.../auth/AuthInterceptor.java`）。新增写接口必须同步登记到上表与拦截器，否则默认公开。CORS 预检 `OPTIONS` 直接放行。

前端路由守卫同口径：`requiresAuth` / `requiresAdmin`，权限不足带 `redirect` 跳 `/login`，登录后原路返回。Axios 收到 `code = 401` 会清除本地会话（`/auth/login` 与 `/auth/register` 自身的 401 属「账号或密码错误」，不会误清）。

## 错误码

| code | 含义 |
|---|---|
| 0 | success |
| 400 | 请求参数不合法（含密码长度、非法角色、不能停用自己等） |
| 401 | 未登录 / 登录已过期 / 账号或密码错误 / token 已失效 |
| 403 | 已登录但权限不足（学生访问管理端、读取他人方案等） |
| 404 | 资源不存在 |
| 409 | 状态冲突（用户名已存在等） |
| 423 | **账号已被临时冻结**：连续输错 5 次密码/账号后 30 分钟内禁止登录，`data` 携带 `lockedUntil` / `retryAfterSeconds` / `maxAttempts` |
| 500 | 服务内部错误 |
| 501 | 能力尚未实现（P0 骨架占位接口曾返回此码，主链路已无占位） |
| 502 | 依赖服务调用失败 |
| 503 | 该省 / 年份数据尚未发布 |

### 文件存储约定（本地磁盘）

- 所有上传文件由 `FileStorageService` 落盘到 `./uploads/{category}/`（`category` ∈ `school`、`avatars`），文件名以 UUID 重命名防冲突与路径穿越。
- 仅允许 `image/png`、`image/jpeg`、`image/gif`、`image/webp`，单文件 ≤ 5MB（`spring.servlet.multipart.max-file-size` 同步限制）。
- `StaticResourceConfig` 将 `/files/**` 映射到上传根目录，可直接 `GET /files/{category}/{name}` 访问（前端 `/files` 已配代理）。
- 生产环境建议将 `admitatlas.upload-dir` 指向共享存储或对象存储挂载点；当前零额外依赖，适合本地与单节点演示。
- 演示账号密码（`admin` / `student` / `demo`）以 `LoginView.vue` 的「一键填入」按钮为准；V5 迁移用 `PasswordHasher` 对同一组口令重算 PBKDF2 哈希，确保全新库与增量升级后都能直接登录。**不要修改 V1~V4**：已应用的迁移内容一旦变更，Flyway 会因 checksum mismatch 拒绝启动。

### 登录失败锁定（V5）

- `login_attempt(username, failed_count, locked_until, updated_at)` 按用户名维度持久化，**重启不丢失**。
- 阈值 5 次 / 冻结 30 分钟，常量在 `AuthService.MAX_FAILED_ATTEMPTS` 与 `AuthService.LOCK_MILLIS`。
- 冻结到期后下一次请求自动重新计数；登录成功即清零。管理员「重置密码」「启用账号」触发 `clearLoginAttempt`，可人工提前解锁。
- 前端 `LoginView.vue` 按账号隔离倒计时（`mm:ss`），冻结期内禁用提交；密码框支持显示 / 隐藏切换。

### 匹配算法口径

1. 规则驱动：`volunteerUnit` / `volunteerCount` 来自 `rule_policy`，缺省才降级到策略默认值并给出 warning。
2. 服务端换算位次 → 批次线过滤（未达线时降级并提示）。
3. 候选召回：位次窗口 `[rank × 0.55, rank × 1.9]` 下推到 SQL，命中 `idx_query (province, year, category, batch, min_rank)`。
4. 按 `schoolCode|groupCode|majorCode` 分组，用当年招生计划做选科资格过滤。
5. 近三年 `min_rank` 按 1 / 2 / 3 加权（越近权重越高），算位次差、相对差、波动率与匹配度。
6. 按 `chongBoundary = -0.10` / `baoBoundary = 0.15` 分档，参数全部来自 `application.yml` 的 `admitatlas.match.*`。
7. 偏好过滤 → 排序 → 限量 → 生成推荐依据 → 落库任务留证（归属当前账号）→ 返回统一免责声明。
