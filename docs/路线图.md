# 路线图

> 当前阶段：**P1 单省试点 + 双身份体系已交付（2026-11）**。默认数据集为演示数据（合成值），真实数据接入与审核发布属于 P2。

- [x] Maven 多模块工程 + 依赖版本仲裁（Spring Boot 3.2.5 / Spring Cloud 2023.0.1 / Alibaba 2023.0.1.0）
- [x] 外层项目根 + `back-end-spring-cloud`（11 个模块平铺）+ `front-end` + `docs` 的目录结构
- [x] 模块化单体：全后端唯一启动类、唯一 `application.yml`、唯一可执行 jar（8080）
- [x] 统一响应 / 错误码 / 全局异常处理 / 共享 DTO 契约 / 模块自检端点
- [x] 匹配策略接口与三种考试模式实现、策略工厂
- [x] Vue3 + Vite + TailwindCSS 前端骨架与主流程页面
- [x] 数据模型建表脚本、接口约定、开发指南、合规说明
- [x] 位次换算接口实现（P1 提前完成）
- [x] 单省 3 年录取数据**演示集**（`demo-2026-hb-v1`，合成值）；真实数据人工整理 / 来源合规确认仍属 P2

## P1 · 单省试点 ✅（2026-11 交付）

- [x] 持久层落地：Flyway `V1__schema.sql` + `V2__seed_demo.sql`；默认 H2 文件库零外部依赖，`application-mysql.yml` 支持 MySQL 8
- [x] `score` 实现 `convert-rank`（精确行 / 插值 / 无表估算）、`segments`、`batch-lines`、`admission/scores`
- [x] `school` 实现院校 / 专业档案检索与详情、字典接口；前端详情页用 ECharts 画历年最低位次趋势（P1 用 SQL 检索，ES 留到 P2）
- [x] `policy-rule` 读取 `rule_policy` 输出本省志愿结构（湖北 45 个院校专业组 / 北京 96 个专业+院校），并实现选科组合校验
- [x] `auth-user` 成绩档案落库，保存时服务端自动换算位次
- [x] `match-engine` 完整链路：位次换算 → 批次线过滤 → SQL 位次窗口召回 → 选科资格过滤 → 近三年加权位次 → 匹配度打分 → 冲稳保分档 → 推荐依据 → 任务留证
- [x] `plan-report` 方案逐条校验（数量 / 序号 / 重复 / 档位 / 选科 / 冲稳保比例）、保存 / 载入、UTF-8 BOM CSV 导出（Excel 可打开）+ 浏览器打印 PDF
- [x] 前端主流程全部接真实数据：成绩录入 → 智能匹配 → 志愿方案 → 院校库 → 首页概览；Pinia 本地持久化、统一 Axios 解包
- [x] 系统概览与数据版本公示（`/api/v1/system/overview`、`/data-version`），全站统一免责声明
- [x] 64 个后端单元 / 服务测试、`mvn clean package` 12 模块 SUCCESS、前端双身份 CDP E2E 与 41 项三视角接口冒烟全绿
- [x] **双身份体系**：Flyway `V3__auth_roles_audit.sql`、PBKDF2 密码哈希 + HS256 JWT + `AuthInterceptor` 三级鉴权、按账号数据隔离、登录 / 注册 / 退出页、管理后台 6 页、操作审计

**P1 的明确边界**：登录鉴权已落地但只有账号密码一种方式（缺手机号验证码与 Token 刷新）、角色只有 STUDENT / ADMIN 两档（缺细粒度菜单权限）、版本发布只有公示状态切换（缺审核汇总 / 灰度 / 回滚）、未接 Redis / Elasticsearch、无后端原生 PDF、匹配为同步执行（`executionMode=SYNCHRONOUS`）、数据为合成演示值。功能点级差异见 [功能清单](功能清单.md) 的「P1 交付对照」。

## P2 · 数据流水线与全国规则（下一步）

- `data-collector` 全流水线：调度、抓取、MinIO 留证、PDF/Excel 解析、质量校验、人工审核、版本发布
- 管理后台补齐：采集任务监控、审核队列、版本发布 / 回滚（已有用户与角色、规则配置、院校档案、数据版本公示、操作审计）
- 规则配置化覆盖传统文理 / 院校专业组 / 专业+院校，支持 45 / 96 / 112 志愿结构（数据结构已就绪，缺管理界面与全国数据）
- 选科过滤补齐单科门槛、语种、体检、同分排序（当前仅选科要求）
- 专业录取分与招生计划入库；接入 Redis 缓存与 Elasticsearch 中文检索
- 手机号验证码 / 微信登录、Token 刷新、审核员 / 运营 / 只读等细粒度角色与菜单权限、多份成绩档案、方案复制 / 重命名 / 删除

## P3 · 提质与拆分

- 风险模型调优（三年波动、计划数变化、大小年修正）、策略参数后台化并留版本
- 候选池预计算 + Redis 缓存 + 匹配异步化与轮询，压测与水平扩容
- 数据版本灰度、质量报告（覆盖率 / 缺失率 / 异常率）
- 接入 Sentinel 限流、SkyWalking 链路追踪、Prometheus / Grafana 监控
- `search` / `job-center` 视负载拆为独立服务；引入 Spring Cloud OpenFeign 契约

## 明确不在当前范围

- 真实录取概率预测与「保录取」承诺（合规风险）
- 商业付费报告、专家复核、志愿代填报
- 未经授权的第三方数据采购与转售
