# 前端视觉规范

> 适用 `front-end/`。本文描述的是**已经落地的实现**，不是设计提案。配色、动效与主题的单一事实来源是 `src/style.css` 与 `tailwind.config.js`。
>
> 视觉参考：用户提供的 PathForge 录屏（`2026-03-09_16-31-39.mkv`）——极浅冷白底、纯白轻卡片、蓝色链接文字、彩色小胶囊、手写体中文大标题、细进度条、大留白。上一版「青瓷 × 墨灰 + 重毛玻璃」已整体替换；**双主题、滚动收缩导航、路由过渡与动效机制全部保留**。

## 一、设计基线

| 项 | 取值 |
|---|---|
| 风格 | 轻盈「纸面」工具界面：极浅冷白渐变底、纯白卡片 + 1px 细边、极轻阴影、大留白、小字号 |
| 强调色 | 明亮蓝：浅色 `#4a6cf7`，暗色 `#7f9dff`（链接、选中态、主按钮、进度条） |
| 底 | 浅色 `#f8f9fd`（渐变 `#fcfdff → #f4f6fd`），暗色 `#0f121a`（渐变 `#111521 → #141a28`） |
| 辅助色 | 薄荷绿 / 天蓝 / 淡紫 / 琥珀 / 陶红 / 青，均作**小面积胶囊或圆形指标**，不作大面积底色 |
| 冲稳保 | 陶红 `#d2694d` / 琥珀 `#c18920` / 青绿 `#2f9d6a`，浅色淡底、暗色半透明底 |
| 字体 | 正文系统中文栈（`PingFang SC / 微软雅黑`），标题 600 字重；**展示标题用本地手写体 Ma Shan Zheng**（子集 26 KB） |
| 圆角 | 卡片 14px、小卡 12px、控件 9~10px、胶囊 999px（明显小于上一版 22px） |
| 布局 | 非对称 `grid-cols-12`（7:5、5:4:3）；首页为居中窄栏 Hero + 下方卡片区 |

**与参考一致的关键形态**：首页手写体问候大标题、副标题、打字机行、4 个彩色圆形状态指标、细进度条 + 「已完成 1/4」小字、蓝色文字链接、蓝色小标题（`.eyebrow`）。

## 二、双主题

主题由 `<html data-theme="light|dark">` 驱动，所有颜色走 CSS 变量，组件内不写死色值。

| 环节 | 实现 |
|---|---|
| 防闪烁 | `index.html` head 内联脚本在首屏渲染前设置 `data-theme` |
| 默认值 | **浅色**（与参考风格一致）；不再自动跟随系统深色，避免打开即进暗色 |
| 偏好 | `localStorage['admitatlas-theme']` 记忆用户手动切换；系统主题变化不再自动改变 |
| 切换 | 顶栏右侧圆形按钮，`useTheme().toggleTheme()`；切换时全站 `background-color/color` 有 0.55s 过渡 |
| 新增组件 | 只使用 `var(--*)` token；新增颜色必须同时在 `:root` 与 `[data-theme='dark']` 定义 |

主要 token：`--bg/-a/-b` `--surface/-2` `--text/-2/-3` `--line/-soft` `--accent/-soft/-text` `--on-accent` `--link` `--glass` `--nav-glass/-border` `--shadow/-soft/-nav` `--halo-a/b` `--mint/sky/violet/amber/rose/teal(-bg)` `--chong/wen/bao-bg/text`。

## 三、组件与手写体

参考界面**没有重毛玻璃卡片**，因此磨砂只保留在三处：滚动后的导航胶囊、路由遮罩、少量悬浮态；卡片回归纯白纸面。

| 类 | 用途 |
|---|---|
| `.glass` / `.glass-flat` / `.glass-strong` | 白卡片（细边 + 极轻阴影）、浅灰信息条 |
| `.spotlight` / `.lift` | 鼠标跟随淡蓝柔光、hover 上浮 3px + 边框转蓝 |
| `.btn` / `.btn-primary` / `.btn-ghost` / `.btn-icon` | 按钮；主按钮蓝色实底 + 光泽扫过，圆角 10px |
| `.field` / `.field-label` / `.chip` | 表单；聚焦 3px 淡蓝光环 |
| `.tag` + `.tag-chong/wen/bao` | 冲稳保小胶囊 |
| `.pill` + `.pill-mint/sky/violet/amber/rose/teal/neutral` | PathForge 式彩色状态胶囊 |
| `.metric-item` / `.metric-circle` | 首页 4 个彩色圆形状态指标 |
| `.progress-track` / `.progress-fill` | 6px 细进度条（薄荷 → 天蓝渐变） |
| `.hand-title` / `.type-caret` | 手写体展示标题（墨迹揭示动画）、打字机光标 |
| `.eyebrow` / `.display` / `.section-title` / `.muted` / `.faint` | 排版层级 |
| `.empty-state` / `.placeholder-bar` / `.data-table` / `.badge` / `.stat-num` | 空态、骨架、表格、徽标、数字 |

**字体文件**：`public/fonts/MaShanZheng.woff2`，由 Ma Shan Zheng 全字集（5.6 MB）按页面实际用字子集化到 26 KB。若后续新增手写体文案，需把新字加入子集字符表并重新生成，否则会回退到 `STXINGKAI / KaiTi`（不会缺字，但字形不同）。

## 四、动效体系

全部只动画 `transform` / `opacity` / `filter`；`prefers-reduced-motion: reduce` 时统一关闭动画并直接显示 reveal 内容。

| 类别 | 实现 |
|---|---|
| 环境 | 3 个极淡光斑 `drift-a/b` 缓慢漂移，无网格、无霓虹 |
| 标题 | `.hand-title` 墨迹式 `clip-path` 从左到右揭示 1.25s；首页打字机行 95ms/字 |
| 入场 | `v-reveal="n"` 基于 IntersectionObserver，淡入 + 上移 16px（去掉上一版的模糊） |
| 数字 | `v-count="121"` 进入视口后三次方缓出计数；`.progress-fill` 宽度生长 |
| Hover | `.lift` 上浮、`.spotlight` 跟随光、按钮光泽、步骤行右移、表格行淡蓝底、箭头位移 |
| 微动 | `float` 浮动、`pulse-dot` 扩散环、`shimmer` 骨架扫光、`icon-swap` 主题图标旋转淡入 |
| 加载 | 匹配按钮触发时三张 shimmer 骨架；策略探测有 loading / 成功 / 失败三态彩色胶囊 |
| 触感 | 所有 `.btn` 按下 `scale(.98)`；`disabled` 有明确低透明度态 |

## 五、导航栏

| 状态 | 表现 |
|---|---|
| 置顶 `scrollY <= 28` | 高 72px、全宽 1280px、完全透明、无边框无阴影；Logo + 副标题 + 带图标小字导航 + 圆形头像融入页面 |
| 下滑 `scrollY > 28` | 收缩为高 56px、宽 1040px、居中的圆角胶囊；白色磨砂 `blur(20px) saturate(160%)` + 细边框 + 浮起阴影；Logo 缩小、副标题收起 |
| 过渡 | 0.55s `cubic-bezier(0.16,1,0.3,1)`，同时过渡高度、宽度、圆角、背景、边框、阴影、backdrop-filter |
| 回到顶部 | 自动恢复融入态 |

实现位置：`AppHeader.vue`（滚动监听 + `is-scrolled` 类）、`style.css` 的 `.site-header / .nav-shell`。滚动监听使用 passive 事件并在卸载时移除；小屏隐藏副标题与导航图标、导航横向滚动。

## 六、路由切换过渡

1. `router.beforeEach` 调 `startRouteLoading()`，全局遮罩 `RouteLoader.vue` 淡入（0.18s）——淡白/淡黑暗色磨砂背板 + 呼吸品牌方块 + 扩散环 + 滑动进度条 + 中文提示「正在准备页面…」。
2. 遮罩最少显示 560ms，`afterEach` / `onError` 调 `stopRouteLoading()` 淡出（0.3s）。
3. 同时 `DefaultLayout` 用 `<Transition name="page" mode="out-in">` 做页面级过渡：离场 0.2s 上移淡出，入场 0.42s 淡入 + 上移 + 去模糊。
4. 首次直接打开页面不显示遮罩，避免开屏闪烁。

## 七、验证口径

| 检查项 | 期望 |
|---|---|
| 默认主题 | 首次打开 `html[data-theme=light]`，`body` 背景 `rgb(248,249,253)` |
| 主题切换 | 背景在 `rgb(248,249,253)` / `rgb(15,18,26)` 间切换，刷新后保持 |
| 手写体 | `document.fonts.check('40px "Ma Shan Zheng"')` 为 true，标题字形完整无方框 |
| 导航收缩 | 置顶 `height 72 / radius 0 / backdrop none`；滚动后 `height 56 / radius 999px / backdrop blur(20px)` |
| 路由过渡 | 跳转瞬间 `.route-loader` 存在，结束后消失，URL 与页面内容一致 |
| 滚动入场 | 滚动后 `.reveal.is-visible` 数量增加 |
| 构建 | `npm run build` 通过，产物含 `fonts/MaShanZheng.woff2`，无硬编码旧配色类 |

回归检查使用 Chrome CDP 实测上述全部项（1440×900，浅色/暗色首页、滚动态、跳转遮罩、成绩/匹配/方案页截图目视核对），脚本为一次性验证工具，不纳入仓库。
