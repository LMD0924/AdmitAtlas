# 前端视觉规范

> 适用 `front-end/`。本文描述的是**已经落地的实现**，不是设计提案。配色、动效与主题的单一事实来源是 `src/style.css` 与 `tailwind.config.js`。

## 一、设计基线

| 项 | 取值 |
|---|---|
| 风格 | 低饱和、单强调色、磨砂玻璃、大圆角、细边框、无渐变文字与霓虹光 |
| 强调色 | 青瓷绿：浅色 `#2f7d70`，暗色 `#7cc7b3`（全站唯一 accent） |
| 底 | 浅色暖象牙 `#f6f7f4`，暗色墨黑绿 `#0c1011`（均为非纯黑非纯白） |
| 语义色 | 冲 陶红 / 稳 琥珀 / 保 青绿，均为低饱和半透明底 |
| 字体 | 系统中文栈 + Outfit/Geist/Satoshi 优先；标题 `letter-spacing: -0.045em`，仅用 400/500 两级字重 |
| 布局 | 非对称 Bento（`grid-cols-12` + 7:5、5:4:3），禁止三列等宽卡片行 |

## 二、双主题

主题由 `<html data-theme="light|dark">` 驱动，所有颜色走 CSS 变量，组件内不写死色值。

| 环节 | 实现 |
|---|---|
| 防闪烁 | `index.html` head 内联脚本在首屏渲染前设置 `data-theme` |
| 偏好 | `localStorage['admitatlas-theme']`；无记录时跟随 `prefers-color-scheme`，系统变化自动响应 |
| 切换 | 顶栏右侧圆形按钮，`useTheme().toggleTheme()`；切换时全站 `background-color/color` 有 0.55s 过渡 |
| 新增组件 | 只使用 `var(--*)` token；新增颜色必须同时在 `:root` 与 `[data-theme='dark']` 定义 |

主要 token：`--bg` `--text` `--text-2/3` `--line` `--glass` `--glass-strong` `--nav-glass` `--nav-border` `--accent` `--accent-soft` `--accent-text` `--on-accent` `--shadow` `--orb-a/b` `--chong/wen/bao-bg/text`。

## 三、毛玻璃与组件类

磨砂三件套：`backdrop-filter: blur(22px) saturate(165%)` + 半透明底 + `inset 0 1px 0 rgba(255,255,255,.28)` 内高光。

| 类 | 用途 |
|---|---|
| `.glass` / `.glass-flat` / `.glass-strong` | 卡片、页面区块、页脚 |
| `.spotlight` | 配合 `v-spotlight`，鼠标位置跟随的柔光（`--mx/--my`） |
| `.lift` | hover 上浮 + 阴影加深 |
| `.btn` / `.btn-primary` / `.btn-ghost` / `.btn-icon` | 按钮；主按钮 hover 有光泽扫过，点击 `scale(.975)` 触感 |
| `.field` / `.field-label` / `.chip` | 表单；聚焦有 4px 光环 |
| `.tag` + `.tag-chong/wen/bao` | 冲稳保标签 |
| `.eyebrow` / `.display` / `.section-title` / `.muted` / `.faint` | 排版层级 |
| `.empty-state` / `.placeholder-bar` / `.data-table` | 空态、骨架、表格 |
| `.badge` / `.hairline` / `.stat-num` | 杂项 |

## 四、动效体系

全部只动画 `transform` / `opacity` / `filter`；`prefers-reduced-motion: reduce` 时统一关闭动画并直接显示 reveal 内容。

| 类别 | 实现 |
|---|---|
| 环境 | 三个光斑 `drift-a/b` 缓慢漂移、细网格背景（mask 渐隐）、轨道环 `orbit` 旋转 |
| 入场 | `v-reveal="n"` 基于 IntersectionObserver，淡入 + 上移 + 去模糊，`--d` 做交错延迟 |
| 数字 | `v-count="121"` 进入视口后三次方缓出计数 |
| Hover | `.lift` 上浮、`.spotlight` 跟随光、按钮光泽、步骤行右移、表格行底色、箭头位移 |
| 微动 | `float` 浮动、`pulse-dot` 扩散环、`shimmer` 骨架扫光、`icon-swap` 主题图标旋转淡入 |
| 加载 | 匹配按钮触发时三张 shimmer 骨架；策略探测有 loading / 成功 / 失败三态 |
| 触感 | 所有 `.btn` 按下 `scale(.975)`；`disabled` 有明确低透明度态 |

## 五、导航栏（DeepSeek 风格）

| 状态 | 表现 |
|---|---|
| 置顶 `scrollY <= 28` | 高 92px、全宽 1320px、完全透明、无边框无阴影，Logo 与导航直接融入 Hero |
| 下滑 `scrollY > 28` | 收缩为高 60px、宽 1020px、居中的圆角胶囊；磨砂底 + 明显边框 + 浮起阴影；Logo 同步 `scale(.82)`、字号缩小 |
| 过渡 | 0.55s `cubic-bezier(0.16,1,0.3,1)`，同时过渡高度、宽度、圆角、背景、边框、阴影、backdrop-filter |
| 回到顶部 | 自动恢复融入态 |

实现位置：`AppHeader.vue`（滚动监听 + `is-scrolled` 类）、`style.css` 的 `.site-header / .nav-shell`。滚动监听使用 passive 事件并在卸载时移除。

## 六、路由切换过渡

1. `router.beforeEach` 调 `startRouteLoading()`，全局遮罩 `RouteLoader.vue` 淡入（0.18s）——磨砂背板 + 呼吸品牌方块 + 扩散环 + 滑动进度条。
2. 遮罩最少显示 560ms，`afterEach` / `onError` 调 `stopRouteLoading()` 淡出（0.34s）。
3. 同时 `DefaultLayout` 用 `<Transition name="page" mode="out-in">` 做页面级过渡：离场 0.22s 上移淡出，入场 0.5s 淡入 + 上移 + 去模糊。
4. 首次直接打开页面不显示遮罩，避免开屏闪烁。

## 七、验证口径

| 检查项 | 期望 |
|---|---|
| 主题切换 | `html[data-theme]` 变化，`body` 背景在 `rgb(246,247,244)` / `rgb(12,16,17)` 间切换，刷新后保持 |
| 导航收缩 | 置顶 `height 92 / radius 0 / backdrop none`；滚动后 `height 60 / radius 999px / backdrop blur(...)` |
| 路由过渡 | 跳转瞬间 `.route-loader` 存在，结束后消失，URL 与页面内容一致 |
| 滚动入场 | 滚动后 `.reveal.is-visible` 数量增加 |
| 构建 | `npm run build` 通过，产物中无硬编码旧配色类 |

回归检查曾使用 Chrome CDP 实测上述四项，脚本为一次性验证工具，不纳入仓库。
