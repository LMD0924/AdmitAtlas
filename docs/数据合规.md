# 数据来源与合规说明

> 本项目所有结论仅供参考，最终以各省教育考试院公布的官方数据为准。

## P1 当前数据声明（务必先读）

当前可运行的 **不是真实录取数据**。默认数据集版本 `demo-2026-hb-v1` 由 `V2__seed_demo.sql` 生成，院校名称、投档分、最低位次、一分一段人数、招生计划**全部为合成值**，仅用于验证工程链路是否正确：

- 全站固定标识：首页 / 页脚 / 匹配结果 / 导出文件均显示「演示数据（合成值）」与数据版本；
- 每条投档记录仍带 `source_url`（指向演示说明页）与 `audit_status`，字段口径与真实数据一致，便于后续平替；
- 匹配结果统一附加免责声明「本结果依据历史最低位次计算的匹配度与风险等级，不构成录取承诺；最终以各省教育考试院公布数据为准」；
- 导出 CSV 额外写入「生成时间」「数据性质」「数据来源说明」三行留证。

接入真实数据的前置条件：完成 `F-D-01~16` 的来源合规评估与人工审核（见 [功能清单](功能清单.md)），审核通过后生成新的 `data_version` 并关闭 `admitatlas.demo-data`。**在演示数据下不得对外提供志愿决策服务**，也不得把演示数值当作真实分数线传播。

## 数据源分级

| 级别 | 来源 | 采集内容 | 是否权威入库 |
|---|---|---|---|
| A | 各省教育考试院官网 | 投档线公示、一分一段表、招生计划、政策文件 | 是 |
| B | 阳光高考平台、教育部院校/专业目录 | 院校档案、专业目录、招生章程 | 是 |
| C | 各高校招生网 | 专业录取分、单科 / 体检 / 语种要求 | 是（补充） |
| D | 第三方数据平台 | 交叉校验 | 否，仅比对 |

## 采集流水线

```
XXL-Job 调度
  → 抓取（限频 / UA / 重试，必要时浏览器渲染）
  → 原始文件入 MinIO（记录 URL、抓取时间、文件哈希）
  → 解析（PDFBox / Tabula、EasyExcel、Jsoup、OCR）
  → 字段映射与字典归一（院校代码、专业代码、科类）
  → 质量校验（分数区间、位次单调、计划数一致、跨源比对、同比波动阈值）
  → 人工审核队列（异常自动打标）
  → 版本发布（data_version 灰度生效）
  → 缓存预热
```

## 合规底线

1. 仅采集**公开发布**的数据，不绕过登录、不破解接口、不采集个人信息。
2. 遵守目标站点 `robots.txt` 与访问频率限制，设置合理爬取间隔与失败退避。
3. 每条记录保留 `source_url`、`source_name`、采集日期与原始数据哈希，支持溯源与纠错。
4. 提供用户纠错入口，错误数据可下架并回滚到上一 `data_version`。
5. 不转售原始数据集；对外展示显著标注数据来源与「仅供参考」声明。
6. 输出**匹配度 / 风险等级**，不输出「录取率」「保录取」等承诺性结论。
7. 商业化前需重新评估数据授权、资质与当地监管要求。

## 关于「对应科目的分数」

公开投档数据一般只有「最低投档分 + 最低位次」，几乎不公开单科成绩。单科分在本系统中作为**规则条件**而非录取数据：

- 同分排序：各省字段序列不同（如语文 → 数学 → 外语 → 首选科目），存于 `rule_policy.sort_fields`；
- 专业单科门槛：如外语 ≥ 120、数学 ≥ 100，存于 `rule_policy.subject_rules`；
- 附加限制：外语语种、口试、体检结论等。

因此 `student_score.subject_scores` 以 JSON 保存，仅参与资格过滤与同分排序，不参与跨年分数比较。
